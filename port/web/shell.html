Logical Journey of the Zoombinis

The 1996 game, decompiled and rebuilt for the web

zbtools decompiles the Windows release of the game back into C++. Here the decompiled code runs in your browser as WebAssembly.

Heads up: the decompilation was almost entirely done by Claude, and this port is not yet fully tested, so you may run into bugs. Your progress is saved in this browser.
